# Gestão de Estacionamento - Aplicativo Android

Bem-vindo ao repositório do aplicativo de Gestão de Estacionamento.

## Sobre o Projeto

Este é um aplicativo Android nativo, desenvolvido em Kotlin, para gerenciar a entrada e saída de veículos em um estacionamento. O objetivo é criar uma ferramenta simples e eficiente para o controle de vagas, veículos e faturamento.

## Funcionalidades Planejadas

- Registro de entrada de veículos (placa, modelo, cor, hora de entrada).
- Listagem de veículos atualmente no pátio.
- Registro de saída de veículos com cálculo do valor a ser pago.
- Histórico de movimentação.

**Este projeto está em desenvolvimento.**
